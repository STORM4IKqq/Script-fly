## Установка

Для работы требуется любой актуальный экзекутор с поддержкой `game:HttpGet` и выполнением `loadstring`. Скрипты подгружаются напрямую из main-ветки репозитория. 

Скопируйте соответствующий блок и выполните его в среде экзекутора.

### Fly & Noclip
Базовый скрипт: три режима полёта, noclip, телепорт, обход античит-зон и кастомный UI.
