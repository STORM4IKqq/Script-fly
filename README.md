## Обзор

**Script-Fly** — это комплексный набор скриптов для Roblox, состоящий из двух независимых модулей:

- **Система Fly и Noclip** — продвинутая механика полета с несколькими режимами, обходом коллизий и сложными системами анти-детекта.
- **Утилита Multi-Fling** — инструмент для массового воздействия на цели с интеллектуальным поиском NPC и автоматическим возвратом на позицию.

Оба модуля оснащены кастомными пользовательскими интерфейсами с плавными анимациями, градиентными эффектами и профессиональной визуальной обратной связью.

## Установка

### Требования

- Экзекутор Roblox с поддержкой функции `game:HttpGet`
- Возможность выполнения `loadstring`
- Стабильное интернет-соединение для удаленной загрузки скрипта

### Быстрый старт

Скопируйте и выполните соответствующий скрипт загрузки в среде вашего экзекутора:

#### Система Fly и Noclip

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/STORM4IKqq/Script-fly/refs/heads/main/Fly.lua"))()
```

#### Утилита Multi-Fling

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/STORM4IKqq/Script-fly/refs/heads/main/Fling.lua"))()
```

> **Примечание**: Скрипты загружаются напрямую из ветки `main` и автоматически обновляются при каждом коммите в репозиторий.

## Возможности

### Система Fly и Noclip
Prostok
**Версия**: v4.2.1

#### Режимы полета

| Режим | Описание | Применение |
|------|-------------|----------|
| **Physics** | Агрессивный полет с использованием PlatformStand и LinearVelocity, неоновым шлейфом и частицами старта | Высокоскоростное перемещение с визуальными эффектами |
| **Swimming** | Стабильное передвижение в воздухе, имитирующее механику плавания | Плавный, контролируемый полет в замкнутых пространствах |
| **Obxod** | Интеллектуальный режим обхода: защита от резинок, автоматический CFrame-glide в зонах блокировки, оптимизация вертикальной скорости | Обход систем античита и ограничений скорости (velocity clamp) |

#### Основные функции

- **Многорежимная система полета** — три различных алгоритма полета, оптимизированных под разные сценарии.
- **Продвинутый Noclip** — обход коллизий с интеллектуальным определением стен, предотвращающим преждевременное отключение.
- **Телепорт по клику (Click TP)** — телепортация на поверхности по клику мыши с использованием Raycast и клавиши-модификатора.
- **Защита от толчков (Anti-Push)** — механизмы Anti-Push и Anti-Slap, предотвращающие внешнее физическое воздействие на персонажа.
- **Система Anti-AFK** — автоматический обход обнаружения простоя, предотвращающий отключение от сервера.
- **Динамическая конфигурация** — настройка скорости в реальном времени (от 1 до 5000 studs/s) с сохранением конфигураций.
- **Мобильная оптимизация** — сенсорные перетаскиваемые кнопки управления для мобильных устройств.
- **Режим PANIC** — система экстренной очистки, удаляющая все элементы GUI, эффекты, подключения и следы выполнения.

#### Схема управления

| Клавиша | Функция |
|-----|----------|
| `R` | Вкл/выкл полет |
| `N` | Вкл/выкл noclip |
| `WASD` | Управление направлением |
| `Space` / `C` | Подъем / Спуск |
| `F` | Режим спринта (множитель 1.8x) |
| `J` | Меню настройки скорости |
| `Insert` | Главный интерфейс |
| `H` | Настройка горячих клавиш |
| `M` | Дополнительные настройки (MISC) |
| `LCtrl` + `ЛКМ` | Телепорт по клику |

> **Кастомизация**: Все горячие клавиши полностью переназначаются через внутриигровой интерфейс.

#### Визуальные особенности

- Режим Rainbow RGB с анимированными эффектами обводки
- Система неонового шлейфа с настраиваемым временем жизни
- Динамическая регулировка поля зрения (FOV) в зависимости от скорости
- Эффект размытия (Gaussian blur) при активации интерфейса
- Частицы при старте полета
- Наклон персонажа (Pitch-tilt) во время полета

### Утилита Multi-Fling

**Версия**: STORM4IK

#### Управление целями

- **Двухвкладочный интерфейс** — раздельные представления для Игроков и NPC с автоматической категоризацией.
- **Интеллектуальный поиск NPC** — автоматическое сканирование потомков workspace для выявления неигровых гуманоидов.
- **Мульти-таргетинг** — одновременное выполнение флинга над несколькими целями.
- **Массовые операции** — функционал ВЫБРАТЬ ВСЕ / СНЯТЬ ВЫДЕЛЕНИЕ для быстрого управления целями.
- **Обновление в реальном времени** — динамическое обновление списка NPC каждые 2 секунды.

#### Механика флинга

- **Манипуляция скоростью** — инжекция высокоскоростных векторов (амплитуда 9e7+) с вращательной силой.
- **Восстановление позиции** — автоматический возврат в исходную точку после завершения флинга.
- **Управление состоянием** — интеллектуальное определение сидящих или невалидных целей с их автоматическим исключением.
- **Сетевая оптимизация** — манипуляция параметром FallenPartsDestroyHeight для предотвращения преждевременного уничтожения частей.

#### Особенности интерфейса

- Кастомный дизайн UI с градиентными фонами и плавными анимациями при наведении
- Индикатор статуса с подсчетом целей в реальном времени
- Цветовое кодирование акцентов для различия игроков и NPC
- Анимированные галочки с эффектами обводки
- Перетаскиваемое окно с кастомной кнопкой закрытия (крестик) для полной очистки памяти

## Использование

### Система Fly и Noclip

1. Выполните скрипт загрузки.
2. Нажмите `Insert` для открытия главного интерфейса.
3. Настройте режим полета в меню MISC (`M`).
4. Нажмите `R` для активации полета.
5. Используйте `WASD` для управления направлением, `Space`/`C` для вертикального перемещения.
6. Нажмите `N` для включения noclip (не отключится, пока вы находитесь внутри стены).
7. Используйте `LCtrl` + `ЛКМ` для телепортации по клику.

### Утилита Multi-Fling

1. Выполните скрипт загрузки.
2. Интерфейс появится автоматически.
3. Выберите вкладку (Игроки или NPC).
4. Отметьте чекбоксы для выбора целей.
5. Нажмите **START** для запуска последовательности флинга.
6. Нажмите **STOP** для прекращения операции.
7. Используйте кнопку закрытия (X) для полной очистки и выгрузки скрипта.

## Конфигурация

### Система Fly

Файлы конфигурации сохраняются в директории рабочей области вашего экзекутора с расширением `.gfly`.

#### Сохранение конфигурации

1. Откройте главный интерфейс (`Insert`).
2. Нажмите кнопку **Сохранить**.
3. Введите имя конфигурации.
4. Подтвердите сохранение.

#### Загрузка конфигурации

1. Откройте главный интерфейс (`Insert`).
2. Нажмите кнопку **Загрузить**.
3. Введите имя конфигурации или вставьте JSON-код напрямую.
4. Подтвердите загрузку.

#### Формат экспорта

Конфигурации сохраняются в формате JSON с сериализацией Enum:

```json
{
  "BaseSpeed": 60,
  "SprintMultiplier": 1.8,
  "FlyMode": "Obxod",
  "ToggleKey": {
    "__type": "EnumItem",
    "enum": "Enum.KeyCode",
    "name": "R"
  }
}
```

## Список изменений

<details>
<summary><strong>v4.2.1 - Оптимизация Obxod и исправление ошибок</strong></summary>

- **Исправление зависания Obxod в воздухе**: Устранена проблема, при которой режим Obxod ошибочно принимал обычный полет за откат сервера (rubber-banding), что приводило к падению скорости в открытом воздухе.
- **Снятие лимита вертикальной скорости**: Убрано искусственное ограничение в 18 studs/s на вертикальную ось, что позволило осуществлять подъем и спуск на полной скорости.
- **Система обхода зон**: Реализована автоматическая активация CFrame-glide при подавлении скорости зонами античита.
- **Исключение вертикальных аномалий**: Вертикальное смещение исключено из алгоритмов обнаружения резинок и блоков, обеспечивая плавный вертикальный полет.
- **Исправление опечатки Enum**: Исправлено `PlatformStand` на `PlatformStanding`, что устранило спам ошибками в консоли F9.
- **Оптимизация восстановления**: Смягчено восстановление после реального отката сервера (коэффициент 0.4 вместо 0.18, окно 0.15-0.5с) для более быстрого возврата к нормальной скорости.
- **Сохранение системы PANIC**: Функционал экстренной очистки из версии v4.2.0 полностью сохранен.

## Технические детали

### Архитектура

Оба скрипта используют модульную архитектуру:

- **Абстракция сервисов** — четкое разделение зависимостей от сервисов Roblox.
- **Управление событиями** — централизованное отслеживание подключений с автоматической очисткой.
- **Управление корутинами** — контроль потоков с поддержкой отмены.
- **Отслеживание Instance** — подсчет ссылок для корректной сборки мусора.
- **Слабые таблицы (Weak Tables)** — энергоэффективное кэширование с использованием слабых ссылок.

### Оптимизация производительности

- **Ограничение Delta Time** — предотвращение физических эксплойтов при просадках FPS.
- **Экспоненциальное сглаживание** — плавные переходы скорости с использованием интерполяции `1 - e^(-k*dt)`.
- **Условный рендеринг** — обновление UI только при изменении состояния.
- **Ленивая инициализация** — сервисы и экземпляры создаются только по мере необходимости.
- **Пакетные операции** — минимизация API-вызовов за счет группировки операций.

### Функции анти-детекта

- **Инжекция шума скорости** — синусоидальные возмущения, предотвращающие идеально линейные траектории.
- **Подмена состояния (State Spoofing)** — манипуляция состоянием гуманоида для избегания паттернов детекта.
- **Учет сетевого владельца** — адаптивное поведение в зависимости от статуса Network Owner.
- **Дифференциация откатов** — различие между реальными серверными коррекциями и обычной физикой.
- **Очистка следов** — полное удаление артефактов выполнения через систему PANIC.
